## 🖋️ Core Concept: The Architect's Workspace & Field Journal

Prismark is an agency operating system where **bespoke craftsmanship meets architectural engineering**. The design language completely rejects sanitized, sterile corporate SaaS templates. It feels like an artisan's physical desk: tactile drafting paper, ruled notebook margins, organic hand-written annotations, stamp seals, and precision vector schematics.

### 🚫 Strictly Forbidden (Anti-AI Slop Rules)
- **NO generic Silicon Valley template UI** (no generic purple/blue gradients, no cookie-cutter rounded card grids).
- **NO sterile corporate stock aesthetics**.
- **NO dead, static screenshots** — all product previews must be live, responsive, and tactile.

## 🎨 Visual Identity & Design Tokens

### 1. The Canvas: Tactile Paper Textures
- **Base Canvas (Light Mode)**: Warm drafting paper (`#fbf9f4` / `#f6f3eb`), parchment cream (`#fdfbf7`), kraft paper accents (`#e8dfd1`).
- **Paper Grid Motifs**: Subtle 5mm engineering graph paper lines, dot grid drafting patterns, or ledger notebook ruled lines.
- **Base Canvas (Dark Mode - The Blueprint Inversion)**: Deep blueprint navy (`#0c192c` / `#0a121e`) with cyan blueprint gridlines, or midnight drafting chalkboard (`#121316`) with chalk-white vector lines.
- **Tactile Paper Elements**:
  - Deckle edges, tear-strip dividers, ruled ledger rows.
  - Stamped ink seals (`PAID`, `VERIFIED`, `APPROVED` in red/vermilion ink stamps).
  - Washed ink highlights / highlighter yellow-gold accents.

### 2. Hand-Written Callouts & Scribble Vector Accents
- **Typography Pairing**:
  - **Primary UI / Text**: Razor-sharp architectural monospace (`Geist Mono`, `JetBrains Mono`) paired with elegant editorial serif or grotesque sans (`Geist`, `Newsreader`, or `Instrument Serif`).
  - **Hand-written Accents**: Authentic script / handwriting font (e.g. `Caveat`, `Reenie Beanie`, `Architects Daughter`, or hand-drawn SVGs) for margin notes, arrows, doodles, circular emphasis marks, and commentary.
- **Hand-Drawn Vector Annotations**:
  - Hand-drawn vector arrows pointing to hero features (*"Client signed here"* / *"Automatically posted to double-entry ledger"*).
  - Organic scribbled circles highlighting key metrics.
  - Wavy hand-drawn underline strokes beneath headline words.
  - Rough hand-sketched boxes around key callouts.

### 3. Precision Vector Engineering Schematics
- Clean, architectural vector line art:
  - Wireframe project pipelines (Gantt milestones rendered as drafting blueprints).
  - Isometric agency organizational schematics.
  - Precision technical vector diagrams for double-entry financial ledger balances.
  - Clean SVG line icons drawn with single-weight architectural strokes.

## 🛠️ Interactive Product Previews & Slices
- **The Blueprint Project Board**: Interactive drafting-board Kanban with tactile task tickets, paper-clip markers, and handwritten priority stamps.
- **The Double-Entry Ledger Sheet**: Ruled accounting ledger notebook with live expanding journal entries, debit/credit balancing, and ink-stamp status badges.
- **The Client Portal Document Desk**: Interactive document signing interface with realistic digital pen signing, draggable signature stamps, and wax/ink seal animations.
- **Interactive Agency Pipeline**: Flowchart linking deals → contracts → invoices → team payouts with vector wiring.
