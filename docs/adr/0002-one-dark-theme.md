# One dark theme

The app is dark only. There is no light mode and no theme switcher, on web or on the phone. Every colour is painted explicitly from the token set, never inherited from the operating system. Supporting two themes doubles the surface every screen has to be checked against, and the design language (monochrome, colour only for state) was built for one ground. The shadcn components had their `dark:` classes stripped rather than left dormant, so nobody has to wonder whether they are live.
